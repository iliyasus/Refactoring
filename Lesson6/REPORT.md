# Занятие 18. Комплексный рефакторинг заказов

Тесты написаны до изменения модуля и проверены на исходном коде: **15 passed**.
После каждого этапа рефакторинга тот же набор запускался повторно; итог — **15 passed**.
Порядок изменений: зафиксировать поведение тестами → назвать бизнес-константы →
разделить расчёт на функции → убрать дублирование отчётов → упростить ветвления
и выделить шаги обработки заказа → уточнить имена и форматирование.

| Проблема | Техника | Результат |
|---|---|---|
| Длинный расчёт суммы и обработки заказа | Извлечение функций (`_apply_promotion`, `_delivery_cost`, `_validate_stock`, `_format_order_report`) | Каждый этап имеет отдельную ответственность; основная функция читается как последовательность шагов. |
| Три почти одинаковых отчёта | Обобщение дублирующегося кода в `_format_category_report` | Одна реализация форматирования; публичные `report_food`, `report_tech` и `report_books` сохранены. |
| Пороги, скидки, налог и сроки заданы числами в выражениях | Замена магических чисел именованными константами | Бизнес-правила видны по именам; значения проще находить и менять. |
| Глубокие вложенные проверки пользователя и адреса | Guard clauses — ранние возвраты в `check_order` | Условия валидации выполняются в исходном порядке, вложенность уменьшена. |
| Неясные шаги и переменные в обработке заказа | Переименование и распаковка позиции на `name`, `price`, `quantity`, `category`; выделение операций | Смысл действий и элементов заказа читается без обращения к индексам кортежа. |

## Фрагменты «до/после»

**1. Магическое число**

```python
# До
if total > 5000:
    total = total - total * 0.15

# После
if subtotal > VIP_HIGH_VALUE_THRESHOLD:
    discount_rate = VIP_HIGH_VALUE_DISCOUNT
```

**2. Вложенная валидация**

```python
# До
if user is not None:
    if user["active"] == True:
        # дополнительные вложенные проверки

# После
if user is None:
    return "no_user"
if not user["active"]:
    return "inactive"
```

**3. Дублированное форматирование**

```python
# До: отдельный цикл и строка форматирования для каждой категории
for item in items:
    if item[3] == "food":
        ...

# После: одна функция для всех категорий
def report_food(items):
    return _format_category_report(items, "food")
```
